# 文献调研 · 结束门(Phase 1)

> 配合 `PROTOCOL.md`。目的:严格界定**何时停**(防过度/不足调研)与**停在哪一格**(多出口)。
> 每个门都给**可检验触发条件**,且裁决必须**自带证据指针**(点名论文 + 引文),使检查 = 读那一段,而非重跑调研。

## 停止准则(三条同时满足才允许退出调研)

1. **深度下限(软)**:每个子域 ≥ 3 篇**读过正文(Tier-1)**的核心论文。低于此一定没调够。
2. **饱和(主驱动)**:连续 **K=3** 轮滚雪球不再带来"与子问题相关的新发现"(以 `saturation-log.md` 曲线为准)。
3. **核心判定题有明确 yes/no**:"有没有人在**与我们相同构念**下测过 P1?" 已可回答。

## 结束门(满足停止准则后,落到其一)

| 门 | 可检验触发条件 | 必带指针 | 动作 |
|---|---|---|---|
| **PASS** | 新颖性在 + ≥1 篇锚点 + 找到 golden-rub 来源 + 文献下 H 仍 plausible | 锚点论文 id;golden-rub 来源 id | → 交用户决策,进入"测量对象与协议"阶段 |
| **NOVELTY-DEATH** | 有人已在相同构念下测出相同结论 | 该论文 id + 原文引文(file:line) | → **回退假设阶段**,切到其未测的侧面重立靶(不弃假设) |
| **TRUTH-DOUBT** | 文献强烈暗示 P1 假(单 rubric 已近完整覆盖) | 证据论文 id + 引文 | → 收窄 H(限定某类任务)重测;压倒性 → 弃 |
| **INSUFFICIENT** | 找不到 golden-rub / 无锚点 / 某子域覆盖不足 | 缺口清单(哪个子域、缺什么) | → **调研未完成,继续**,不许退出 |
| **SCOPE-SHIFT** | 调研暴露出一个更好的邻近问题 | 新问题陈述 + 触发它的论文 id | → **上报用户决策**(唯一打断自主循环的情形) |

## HITL 边界

- **入口**:用户批准 `PROTOCOL.md` = 人类门(已过则自主执行)。
- **执行中**:自主无 HITL,除非 `SCOPE-SHIFT`。
- **出口**:执行会话交出口自评(`PROTOCOL.md` §7)+ 落定的门 + 指针,由用户决策是否进入下一阶段。
  此自评同时是日后"下游卡住、回看本阶段是否出错"的审计依据。
