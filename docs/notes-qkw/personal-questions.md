- [x] 明确正确驱动模式
  - 一些实体：
    - 问题
    - 方法——用于解决问题
    - 机制——用于解释问题原因
  - 如果还没有发现问题：不能“先有方法，后找问题”，但是允许“先假设存在一类问题，再找问题是否存在，最后设计方法”。
- [x] 文献调研是否能证伪假设
  - 能证伪假设的：只有实验。——文献调研不测量世界。
  - 文献调研能做到的：
    - 报告能证伪假设的实验。——提供间接证据，而非证伪。这不全是因为结果不可轻信（第三次要原因）、解释不可轻信（第二次要原因），而是因为构念/设置/操作不同（第一主要原因）。
    - 报告了我们的实验现象。——我们的想法失去了新颖性。
- [x] 【名词解释】在机制解释里，什么是：方差、解释方差、额外方差
  - 方差：随自变量**实验设置**（例如模型、任务）变化，因变量**目标现象**（例如bias现象）有强有弱，这种波动就是方差。
  - 解释方差：预测一些**实验设置变量**，将它们和目标现象做回归，如果变量高、目标现象强，变量低、目标现象弱，那么它就解释了一部分方差。量化指标是R^2。注：解释方差!=证明因果。
  - 额外方差：在现有解释之外的其它方差。在已经放入旧变量后，再加入新变量，看R^2还能上升多少；上升的就是额外方差。
  - 换句话说，“新的**预测模型**相比旧的预测模型，做出的预测和真实结果之间的**差异**平方和**少了多少**”。
  - 据此纠正的误区：
    1. 能解释方差的**不都是**实验设置**变量**（引入新的变量来解释方差），也可以修改预测模型。
    2. 机制研究**不应该**提出**全新**的解释框架，而是应该包含前人的解释、做增量，解释额外方差。
    3. 报告结果不能只报告解释了多少方差，而是应该报告在前人工作基础上解释了多少额外方差。
- [x] 调研目标条目 != 预期现象条目
  - 预期现象是我们希望看到的现象，但它不一定成立，因此存在“与预期相反的现象”。
  - 如果调研目标里只有“与预期相符的现象”，那么我们的调研会存在系统性偏差。
  - 更合理的调研目标设置是同时设置两者、两方向都调研。
