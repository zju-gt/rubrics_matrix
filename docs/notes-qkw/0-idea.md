- 一些实体：
  - single-rub：单一LLM生成的rubric
  - multi-rub：多模型/多视角组装的rubric
  - golden-rub：真实评价标准rubric
- 研究问题：单一LLM生成的rubric对任务的真实评价标准rubric的刻画**有多不完整**？这种不完整是**系统性**的吗？多模型/多视角组装的rubric能否**弥补**这种不完整？
- 可证伪假设：单一LLM生成的rubric只**覆盖**真实评价标准rubric的一部分；多模型/多视角组装的rubric能提高**覆盖率/一致性**，且增益主要来源于**互补性**而非**冗余**
- 一些预测：
  - H1：
    - [ ] single-rub的部分覆盖性：single-rub对专家标准的**覆盖率**显著 < 1
    - [ ] cross single-rub的互补性：不同rub的覆盖之间**重叠率**低
    - [ ] multi-rub的**组装增益**：multi-rub的覆盖率 > max(single-rub的覆盖率)，且随加入的rub增加存在上限
  - H2：
    - [ ] 覆盖性差异**导致bias**：覆盖golden-rub的不同评价侧面的，不只是“LLM生成的rubric”（评价时属性），而是LLM的内禀属性——在评价时和作答时都只覆盖一组侧面，且覆盖同一组侧面，因此才出现bias
    - H2是一个独立且额外的机制解释预测，与现有主流且成熟的bias解释不同，且其成立与否不影响我们的主要工作脉络。
    - H2的对手：主流解释。包括：风格熟悉度、perplexity、自我识别。H2要成立，需要证明“覆盖差异”能解释这些解释之外的额外方差。
