**先说一个前提。** arxiv 原文在我这边打不开，我对 GenRubric 矩阵的理解是从论文摘要、HTML 片段和一篇公开评审里拼出来的：

- **矩阵是什么：** 同一个模型对同一个问题采样 K 份 rubric，每份 rubric 让模型照着它写出一个回答。然后用每份 rubric 给所有这些回答打分，并按该 rubric 的满分归一化，得到 K×K 的交叉评价矩阵。
- **怎么挑最优：** 一份 rubric 诱导出的回答在其他 rubric 下的平均分（去掉对角元），就是它的"全面性"分数，GenRubric 拿它当 RL 奖励。
- **对你们最关键的一点：** 矩阵里所有视角都来自同一个模型。公开评审也指出了这个弱点：如果这些视角有共同的盲区，矩阵测到的只是模型的自洽。

行列约定和归一化项的具体定义，建议对照原文 Eq. 6 核对一下。

**整体叙事线：**

- **实证：** 把 GenRubric 的矩阵扩展到"多模型 × 多视角 × 多粒度"，每行每列标上来源，按模型排序做热力图。预期能看到四个结论：
  - 同一模型的 rubric 偏爱自家 rubric 诱导出的回答，矩阵呈块对角结构；
  - 只在单个模型内部挑出的"最优" rubric，和在全矩阵里挑出的不一致；
  - 对同一个模型多采样，效果很快饱和，加模型或加视角则还能继续提升；
  - 分解不一致的来源，模型差异占主导，采样差异最小。

  其中块对角结构适合做 Figure 1，和 GenRubric 的单模型矩阵左右对比。
- **核心洞察：** 把科文的"部分建模"说得更精确：聚合效果取决于各视角误差的相关性，而不是 rubric 的数量。K 个误差相关系数为 ρ 的估计取平均，误差方差是 ρσ² + (1−ρ)σ²/K，其中 ρσ² 这一项不随 K 下降。同一模型的采样 ρ 高，所以多采也降不下去；换模型、换视角能降低 ρ。
- **方法：** 回到矩阵，做三个有几何意义的操作，每个对应一条实证发现：
  1. **块掩码去偏：** GenRubric 去掉的是对角元，我们去掉整个同模型块，只看跨模型的评价。
  2. **谱共识：** 取跨模型评价的主方向作为共识，每份 rubric 和这个方向越接近，质量越高。
  3. **体积组装：** 在保证质量的前提下，挑一组差异最大、覆盖面最广的 rubric，合并成最终的 rubric。

  一句话概括：用多样性来生成，用共识来验证。整个方法不需要训练。

**写作上要注意一点：** "采样出的 rubric 是部分视角"GenRubric 已经写了，所以"部分建模"本身不能当新 insight，我们的增量要落在"这些视角是相关的"。另外，块对角结构也可能是打分 judge 自身的偏好造成的。实证里最好固定一个和所有生成模型都不同家的 judge，再做换 judge 的实验，否则审稿人会问。

稿子最后列了待确认的几项：Figure 1 的形式、第三步在 rubric 级还是 criterion 级做、方法名、下游实验做不做。

大纲按你的六点改好了：

1. **动机**：只讲三件事，部分建模视角、现有方法怎么聚合多份 rubric、它们的局限（视角都来自同一个模型，还默认这些视角彼此独立）。

3. **核心洞察**：标题定为"自洽不等于正确"，有三层：
   - **误差分解**：把一份 rubric 的偏差拆成三部分：所有 LLM 共有的偏差 c、该模型特有的偏差 b_m、单次采样的噪声 ε。
   - **聚合极限**：只用一个模型时，采样再多误差也停在 σ_c² + σ_b²，只有换不同模型才能降到 σ_c²。这一点正好解释了重采样饱和。
   - **不可辨识性**：在同一个模型内部，b_m 和真实信号分不开，任何基于自洽性的度量都无法区分"真实共识"和"共同偏差"。实证里看到的块对角结构，就是 b_m 的可视化。

   最后加了一个测量学类比：同一工具重复测量只能说明它稳不稳定，说明不了它准不准。这个类比是我加的，你们觉得多余可以删。
4. **方法**：三步都写了具体做什么和对应的几何含义，并用一个"2 型糖尿病饮食建议"的 6×6 矩阵从头走了一遍：
   - **遮掉同源打分**：如果只看模型 B 自己的 rubric，会选出 B1；跨来源看，B1 诱导出的回答得分很低。
   - **找共识**：用秩一近似算出每份 rubric 的质量，以及它作为评委的可靠性。
   - **组装**：A2 和 A1 侧重相同，只留 A1；C2 侧重不同，即使质量略低也选入；B1 含有"推荐生酮饮食"这类不当准则，质量低，不选。

   第三步用"去掉共识方向后的残差"来刻画每份 rubric 的独特侧重，这是我定的设计，你们可以再斟酌。
5. **实验**：只写了三类，与专家 rubric 的一致性、作为 GRPO 的奖励信号、Best-of-N 选择，外加一行对比基线。
