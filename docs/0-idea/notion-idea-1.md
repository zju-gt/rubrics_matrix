# Rubric-Anything: Recursive Self-Improvement for Unified Rubric Generation

模型的持续改进依赖于有效反馈，而有效反馈首先需要明确的评价标准。面对开放式问答、专业研究和自主交互，单一答案或整体分数难以充分表达任务要求。Rubrics 将这些要求分解为细粒度的评价条件，为模型评测与优化提供具体依据。然而，高质量标准的构建依赖专业知识和人工投入，难以覆盖不断扩展的任务空间。arXiv 因此，我们需要的不只是一批适用于不同领域的 rubrics，而是一种能够为新任务建立标准、并从实践中持续改进的通用能力。

现有工作通过行为反馈学习生成策略，通过领域研究发现评价要求，并进一步将构建经验转化为可复用的生成器技能，推动了 rubric generation 从一次生成走向持续优化。arXiv 然而，持续优化的效果取决于反馈能否准确反映标准质量。已有研究发现，偏好判断准确率的提升，可能伴随生成标准与专家标准的一致性下降。arXiv 这意味着，生成器需要改进，指导它的测试、诊断和修订反馈同样需要检验。面对新领域，如果这些反馈仍需逐一人工设计，通用生成的困难就只是从生成器转移到了环境。**能否让同一个生成器在为不同任务建立标准的同时，也利用自身能力改善指导下一轮学习的反馈？**

我们的核心认识是：**跨领域的共性不在于评分标准本身，而在于发现和检验标准的方法。** 我们将 rubrics 视为关于任务成功条件的可检验假设，通过证据发现遗漏、纠正误判。进一步，反馈本身也是需要评价的对象：测试是否有效、诊断是否有据、修订是否合理，同样可以通过明确的标准加以检验。因此，标准构建能力不仅能够服务于下游任务，也能够用于校准生成器自身的反馈环境。

基于这一思想，我们提出 **Rubric-Anything**，一个通过递ISO归自改进（RSI）实现统一 rubric 生成的智能体框架。给定任务，agent 获取所需知识、构建候选标准，并通过下游任务中的使用与测试收集反馈。与此同时，它为反馈过程构建 rubrics，检查测试、评分理由和修订建议，并结合外部证据判断问题来自标准还是反馈。经过确认的标准缺陷用于更新生成策略，反馈缺陷则用于改进环境中的测试与诊断机制。由此，生成器与反馈环境形成双向改进：**以 rubrics 校准反馈，以反馈改进 rubrics。** 每轮有效更新被保留为共享的生成、测试与修订策略，影响下一轮的构建和学习。任务目标与独立验收依据保持固定，持续演化的是发现要求、检验标准和获取反馈的方法。

我们将在不同领域的现有基准上研究 Rubric-Anything，覆盖文本回答、代码产物与智能体交互等评价对象，并构建带有依据和验证记录的 rubric 增强评测层。实验将从标准质量、反馈可靠性和跨领域迁移三个方面展开，检验生成标准能否覆盖任务要求、识别真实缺陷并避免误罚。为验证双向改进，我们还将把演化后的反馈环境用于同一个初始生成器，在相同预算下比较学习效果，并通过独立、固定的评价协议检验最终标准。这将帮助区分逐题修订的局部收益与构建能力的持续提升，同时考察奖励投机和多轮演化中的性能退化。

本研究的预期贡献包括：

1. **生成器与反馈环境双向改进的统一框架。** 提出 Rubric-Anything，将标准发现与检验方法同时用于下游任务和自身反馈，通过 RSI 持续改进跨领域的标准构建能力。
2. **可追溯的跨领域 rubric 增强基准。** 为现有基准补充细粒度评价标准，提供证据来源、验证案例与修订记录，支持对标准及其构建过程的审查和复用。
3. **面向双向自改进的系统验证。** 联合评估标准质量、反馈可靠性与跨领域迁移，通过生成器和反馈环境的独立对照，检验系统是否改善了后续构建与学习，而不仅是提高了内部评分。
